WHAT WAS RUN
Primary H2 exactly as in CONVENTION3 §4, in all 16 contexts. The universe is V, the observed genes. Lambert TF is compared with every other
gene in V. The score is the leave-one-out mean cosine to the TF set (stats3.tf_scores_loo) of the V-centred 512-d embedding, computed per layer.
The statistic is the detection-stratified AUROC (stats3.stratified_auroc, strata = node_labels det_decile). The null is N = 10,000
within-stratum label permutations (stats3.permute_within_strata). Each permutation is applied jointly to all 12 layers, and the LOO scores
are recomputed for every permuted TF set in batched matrix form. Max-T is taken over the 12 layers (stats3.max_t_adjust). Intervals are a
gene bootstrap with B = 1,000. Scripts: e3_lib.py, e3_primary.py, e3_bandscan.py, e3_crossfit.py, e3_ledger.py, prep_static.py,
e3_extra.py, e3_finalize.py, e3_report.py. Job list: jobs.txt, run via run_job.sh, logs in logs/.
The vectorised kernels are checked against the stats3 scalar functions on the observed labels in every run (|diff| < 1e-9).
I independently recomputed lung L2 stratified AUROC 0.66319 and ESM2-15B lung 0.88110 with stats3 directly; both match bit for bit.

INFERENCE
TF identity is linearly recoverable from scGPT's contextual gene embeddings beyond detection frequency. This holds after logistic adjustment
for both detection and mean expression, and it replicates in an independent lung atlas. The recoverable signal is modest (AUROC about 0.66)
and is spread over many directions rather than living in a specific narrow band. The static gene-token embedding of the same model carries
more TF-identity information than the residual stream in the main contexts (+0.08 to +0.14 in lung and lung_external). A protein language
model that has never seen expression (ESM2-15B per-protein) carries far more (AUROC 0.88, +0.21 to +0.26 over any layer). The contextual
representation is therefore not where this "knowledge" is best represented.

HYPOTHESIS (not tested here)
TF identity in the residual stream may largely be inherited from the input gene-token embedding, which is diluted through depth (the AUROC
declines L5 -> L11). ESM2's advantage plausibly reflects DNA-binding-domain sequence families, which define the Lambert census.

WHAT THIS DOES NOT SHOW
- That the model uses TF identity causally, or that it represents regulatory relations. That is H3, in E4.
- That any specific screen band is special: screen bands are weaker than the full representation in lung and lung_external.
- That the residual stream adds TF information beyond the static token embedding. That was not tested by conditioning.
- That the checkpoint differences are significant: no paired test was run.

LIMITATIONS
- Bootstrap CIs resample genes with the LOO scores held fixed; the TF centroid is not re-estimated per resample.
- The width-1 band scores use raw coordinates with a sign-free AUROC, so the l2norm k = 1 pitfall does not arise.
- The LDA variant is in-sample.
- Contexts are not independent: lung and immune share donors, kidney_A and kidney_B share a donor, and the checkpoint contexts share cells.
- Mean expression is a residual confounder within detection strata; it is handled only by the logistic adjustment.
- The ESM2 comparison uses 94-96% of V in lung and lung_external, and paired differences use exactly those genes.
- Errata item 3 (delete-d rescaling of vertex-subsampling intervals) does not apply: E3 has no vertex-subsampling interval, only gene bootstraps.

SURPRISES
- The static token embedding and ESM2-15B beat every residual layer.
- Immune SV5-7 at L11 is anti-informative (0.256).
- Cross-fitted band selection helps only in lung_external.
